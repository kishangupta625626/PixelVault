# PixelVault ◆

A personal bookmark manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add website links with a title, category and note
- Search saved links
- Filter by category
- Mark favourites and delete links
- Responsive design for laptop and mobile
- Saves links in browser localStorage

## Run locally
Keep `index.html`, `style.css`, and `script.js` in the same folder, then open `index.html` in your browser.

## Tech
HTML5 · CSS3 · JavaScript

## Storage note
Saved links stay in this browser on this device. They are not automatically synced to GitHub.
